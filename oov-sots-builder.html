How to use the OOV/SOTS Builder

1
The Fixed Shape OOV/SOTS is a fixed building block: ON CAM (presenter reads to camera) → TAKE VO (reporter voiceover with shots logged against it) → TAKE SOT (one clean soundbite) → Out. There's no return to script — no OOV-SOT-OOV.
2
Shot Logging (TAKE VO) Write the reporter's voiceover narration in the VO Script box, then drag shots onto the board below it to log what's on screen while it plays. Each shot gets a visual description, optional NAT sound, and a duration in seconds that you set by eye — no scripting or tags needed per shot.
3
The Lower-Third Is Already Burnt In Name/Title on the SOT are a record of what's already on the tape, not an instruction to graphics. Students deliver OOV/SOT footage as a single file with the lower-third burnt in.
4
Two Different Cutaways The ending Cutaway is what the piece resolves to once the SOT finishes. A mid-interview cutaway is a visual cut-away during the soundbite — audio keeps running continuously under it. Mark one by viewing the transcript and selecting a span of text.
5
The 50±3 Timing Rule ON CAM is estimated from word count ÷ 3, since there's no picture to time it against. The OOV segment uses whichever is longer of the shots you've logged or the script's word-count estimate — a reporter can't read faster than the words take, so if your shots run short of the script, the segment still can't be shorter than the read. The SOT's Runs= is manually timed by you, because spontaneous speech doesn't pace like scripted delivery. Real newsroom arithmetic, not a guess.
